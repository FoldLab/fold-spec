# Governance

This repository is an initial implementer draft. It does not claim a standards body, elected committee, public maintainer roster or certification service.

The publishing repository owner acts as the initial maintainer and appoints reviewers. Changes to normative behavior require review of semantics, migration, fixtures and security. A reviewer should not approve an interoperability claim based solely on screenshots or the author's own validator.

A stable 1.0 release should have at least two independently implemented consumers for the profiles it advertises, a frozen conformance corpus, explicit unresolved issues and a reproducible release record. Draft versions use distinct identifiers; draft compatibility is never inferred from a major number alone.

Historical revisions remain accessible. Corrections document their affected profiles and whether old examples change meaning. Registration of a MIME type, file association, namespace authority or domain is a separate task, not achieved by including a proposed string in this repository.
