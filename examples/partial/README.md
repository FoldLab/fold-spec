# Partial instruction lesson

`partial.fold.json` contains a valid resolved center fold, followed by an unfold whose animation has not been authored. Text for both actions is present. A player stops at the boundary and can continue in Text mode; it must not guess the missing physical movement or resume later geometry beyond that gap.

The proposed final display describes the intended opened sheet without claiming that pose is available from this file. This example is deliberately incomplete in animation but complete in its availability disclosure.
